# 캡컷 에이전트

영상을 **캡컷 드래프트**로 만든다. 최종 MP4 를 굽지 않는다 — 캡컷에서 사람이
이어서 손보는 것이 전제다.

## 먼저 확인할 것

```bash
python3 -m capcut_agent.cli check
```

`MISS` 가 있으면 옆에 설치 명령이 같이 나온다. 그걸 사용자에게 알려주고 멈춘다.
**대신 설치하지 않는다.**

전사 백엔드는 트랙에 따라 다르다. Mac M칩은 `pip install mlx-whisper`,
그 외는 `pip install faster-whisper`.

## 명령 고르기

| 사용자가 원하는 것 | 명령 |
|---|---|
| 자막만 | `caption <영상>` |
| 자막 + 무음 컷 | `caption <영상> --cut` |
| 세로 숏폼으로 | `caption <영상> --cut --shorts` |
| 무음 컷만 (자막 없이) | `cut <영상>` |
| 긴 강의에서 숏폼 여러 개 | `shorts <영상>` → 사용자 승인 → `build <계획파일>` |
| 화면에서 관리 | `serve` (http://127.0.0.1:8765) |

`--inbox` 를 주면 `~/CapCutAgent/inbox/` 안의 영상을 전부 처리한다. 파일명에
공백·괄호가 있어도 따옴표를 씌울 필요가 없다.

## 반드시 지킬 것

**1. 빌드 성공은 검증이 아니다.** 드래프트를 만들었다고 "완료" 라고 말하지
않는다. 사용자가 캡컷에서 처음부터 끝까지 재생해 봐야 끝난다. 매번 이렇게
안내한다 — 캡컷이 실행 중이면 완전히 종료 후 재실행(목록이 갱신되지 않는다),
프로젝트 열기, 재생.

**2. 긴 영상은 짧게 먼저 해본다.** 40분짜리는 전사에만 10~20분 걸린다. 설정이
틀렸으면 그 시간을 전부 버린다. 30초만 잘라 먼저 확인하도록 권한다.

```bash
ffmpeg -i 원본.mp4 -t 30 -c copy 테스트30초.mp4
```

**3. 긴 작업은 백그라운드로 돌리고 기다리지 않는다.** 전사는 수십 분이 걸릴 수
있다.

**4. 사용자 영상을 임의로 지우거나 옮기지 않는다.** `caption` 은 원본을 건드리지
않는다. `cut --inbox` 는 처리 후 `done/` 으로 옮긴다 — 그 동작을 미리 알린다.

## 자주 쓰는 조정

| 증상 | 옵션 |
|---|---|
| 말 첫·끝 음절이 잘린다 | `--padding 0.15` |
| 컷이 너무 적다 | `--noise-db -28` |
| 조용한 녹음인데 말까지 잘린다 | `--noise-db -45` |
| 자막이 화면 밖으로 넘친다 | `--font-size` 를 키운다 (한 줄 글자 수가 자동으로 준다) |
| 자막 위치 | `--speech-y`, `--title-y` (캔버스 픽셀, 중앙 0, 위가 양수) |
| 모션이 과하다 | `--motion fade` 또는 `--motion none` |
| 세로 크롭에 인물이 안 들어온다 | `--anchor top` / `left` / `right` |

## 결과 읽기

`--json` 을 주면 마지막에 `__CAPCUT_JSON__ {...}` 한 줄로 구조화된 보고서가
나온다. 드래프트 경로, 자막 장수, 컷 조각 수, 캔버스 크기가 들어 있다.
사람에게 보고할 때 이 값을 쓴다.

기록은 `~/CapCutAgent/reports/` 에, 대본은 `~/CapCutAgent/scripts/` 에 남는다.
자막이 이상하면 대본을 먼저 보여준다 — whisper 가 못 들은 건지 이쪽 문제인지
거기서 갈린다.

## 알려진 함정 (코드가 이미 처리하지만, 건드릴 때 깨뜨리지 말 것)

1. 타임라인 파일 이름이 버전마다 다르다 → `draft_content.json` 과
   `draft_info.json` 두 이름으로 같은 내용을 쓴다.
2. `draft_meta_info.json` 의 `tm_duration` 이 0 이면 캡컷 홈에서 `00:00` 으로 뜬다.
3. 세그먼트의 `extra_material_refs` 4종이 없으면 클립이 검은 화면이 된다.
4. **macOS 캡컷은 샌드박스** 안에서 돈다. 컨테이너 밖 파일을 못 읽어
   "파일에 액세스할 수 없음" 이 뜬다 → 미디어를 드래프트 폴더 안으로 들인다.
5. **원본 이동은 드래프트 생성보다 먼저.** 경로가 박혀 들어가기 때문이다.
6. 아이폰 `.MOV` 는 회전 메타데이터를 쓴다. 무시하면 비율이 뒤집힌다.
7. whisper 는 한국어 어절을 쪼갠다. 선행 공백으로 복원한다 — **strip 하기 전에.**
8. 컷을 하면 자막 끊는 신호(쉼)가 사라진다 → 컷 경계를 자막 생성기에 넘긴다.
9. 자막 위치는 `transform.y`, 캔버스 절반 높이가 1 인 정규화 값이다.

자세한 내용은 `capcut-agent/README.md` 의 "알려진 지뢰" 를 읽는다.
